A responsive, high-contrast dark theme personal portfolio website built using **HTML5** and **CSS3** for Web Technologies Mini Project 1.

---

## 🌟 Features & Sections

1. **Home:** Introduction, profile picture ring, career objective, and high-contrast hero buttons.
2. **About Me:** Information about academic background, interests, hobbies, and goals.
3. **Education:** Clean tabular presentation of academic qualifications.
4. **Skills:** Categorized layout displaying web development, programming, and soft skills using CSS Grid.
5. **Projects & Achievements:** Interactive card layout featuring CSS-only popups/modals.
6. **Contact:** Direct links to email, phone, location, GitHub, and LinkedIn profiles.

---

## 🛠️ Technical Stack

- **HTML5:** Semantic structural markup (`<header>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
- **CSS3:** Dark-contrast styling, Flexbox, CSS Grid, media queries for responsiveness, hover animations, and modal overlays without using JavaScript or CSS frameworks.
